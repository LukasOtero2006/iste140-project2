# Unplugged: A student guide to screen time and digital wellbeing

ISTE-140 Web & Mobile I, Project 2 (Version D)
Author: Lukas Otero, RIT Croatia
Date: November 2026

## About the project
A multi-page website about smartphones, apps and digital wellbeing, written for students. It covers how apps are designed to hold our attention, compares tools that help manage screen time, and includes a 7-day experiment based on my own phone data.

## Pages
| File | Content |
|------|---------|
| index.html | Home: how much time we spend on phones, benefits, challenges, what digital wellbeing means |
| hooked.html | Designed to Hook You: persuasive design patterns and how push notifications work (with diagram) |
| tools.html | Tools Compared: comparison table of screen-time and focus apps |
| experiment.html | 7-Day Experiment: my own Screen Time data, averages, screenshots and reflection |
| glossary.html | Glossary: 18 key terms in a definition list |
| references.html | References: all sources in APA 7 format |
